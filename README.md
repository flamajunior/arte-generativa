# Caleidoscópio Vivo

Arte generativa interativa que roda direto no navegador. Centenas de partículas seguem um campo de fluxo e são desenhadas com simetria rotacional (e espelhada), formando padrões de caleidoscópio que mudam o tempo todo.

Tudo fica em um único arquivo, `index.html`, feito com HTML, CSS e JavaScript puros, sem dependências.

## Como usar

1. Baixe ou clone este repositório.
2. Abra o `index.html` no navegador. Não é preciso instalar nada nem rodar um servidor.
3. Clique e arraste na tela para jogar tinta.

## Controles

| Controle | O que faz |
| --- | --- |
| **Paletas** | Neon, Oceano, Fogo, Floresta e Arco-íris |
| **Simetria** | Quantas vezes o desenho se repete em volta do centro (1x a 16x) |
| **Partículas** | Quantidade de partículas na tela (20 a 800) |
| **Caos** | Quanto o campo de fluxo se retorce |
| **Velocidade** | Rapidez do movimento das partículas |
| **Espessura** | Largura dos traços |
| **Rastro** | Quanto tempo os traços demoram para sumir (∞ = nunca somem) |
| **Espelhar** | Adiciona o reflexo de cada traço |
| **Brilho** | Soma as cores onde os traços se cruzam |
| **Cores vivas** | Faz as cores girarem lentamente pelo círculo cromático |
| **🎲 Surpresa** | Sorteia paleta, parâmetros e um novo campo de fluxo |
| **⬇ Baixar PNG** | Salva a imagem atual |

## Atalhos de teclado

| Tecla | Ação |
| --- | --- |
| `Espaço` | Pausar / continuar |
| `R` | Surpresa |
| `C` | Limpar a tela |
| `S` | Salvar PNG |
| `H` | Esconder / mostrar o painel |

Em telas menores que 600px, o painel vira uma gaveta na parte de baixo da tela.
